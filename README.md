# From Pixels to Worlds

An intuition-first journey through generative AI, explained through one problem: making a still image come alive.

This repository is intentionally a plain static site. It contains only HTML, CSS, images, and the `.nojekyll` marker used by GitHub Pages.

## Published site

https://parnab.github.io/genai-from-first-principle/

## Structure

- `index.html` — milestone landing page
- `milestone-1/index.html` — full Milestone 1 article
- `assets/site.css` — shared presentation styles
- `milestone-1/*.png` — article illustrations

No Node.js runtime, package manager, framework, or build step is required.
